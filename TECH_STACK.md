# Roamora Tech Stack

This document outlines the technologies and frameworks used to build the **Roamora AI Travel Planning & Experience Engine**.

## 1. Frontend (Web)
- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **UI Components**: Custom glassmorphism, dynamic responsive design

## 2. Backend (API & AI Orchestration)
- **Framework**: [FastAPI](https://fastapi.tiangolo.com/)
- **Language**: [Python](https://www.python.org/)
- **Server**: [Uvicorn](https://www.uvicorn.org/)
- **Data Validation**: [Pydantic](https://docs.pydantic.dev/)

## 3. AI & Machine Learning Layer (Planned)
- **LLM API**: Google Gemini API
- **Agent Orchestration**: LangGraph / CrewAI
- **Embeddings/Vector DB**: Pinecone / Weaviate
- **Recommendation Engine**: Python-based collaborative filtering

## 4. Infrastructure & Data (Planned)
- **Databases**: PostgreSQL (Relational), MongoDB (Document), Redis (Caching)
- **Cloud Provider**: Google Cloud Platform (GCP)
- **Real-time Engine**: WebSockets

## 5. Development Tools
- **Package Managers**: `npm` (Frontend), `pip` (Backend)
- **Version Control**: Git / GitHub
- **Code Quality**: ESLint, Prettier
